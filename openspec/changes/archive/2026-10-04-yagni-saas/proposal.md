## Why

graphwiz.ai wants a web presence for the YAGNI principle — and the medium must be the message. Most tool websites ship the exact over-engineering their users suffer from. **yagni.graphwiz.ai** will be the counter-example: a complete SaaS site with nothing in it.

## What Changes

- New static one-page site at `yagni.graphwiz.ai`
- Zero runtime dependencies: no JS, no backend, no database, no auth, no billing, no cookies, no analytics
- One file (`index.html`), one capability, deployable to any static host

## Capabilities

### New Capabilities

- `landing-site`: the single static page — content, self-sufficiency, deployability

### Modified Capabilities

- (none — greenfield)

## Impact

- New repo `yagni/`; static hosting config for `yagni.graphwiz.ai` (DNS/CDN handled outside this change)
- No code dependencies, no runtime, no data collection — nothing to maintain
